FMD / MSFO analyst — полная папка проекта

В комплекте:
- Python-код проекта;
- templates / static;
- база данных и расчетные файлы;
- сохраненные котировки;
- отчеты и скриншоты / источники;
- requirements.txt.

Намеренно не включены:
- venv (локальное виртуальное окружение; создается заново);
- __pycache__;
- .env (может содержать секреты и локальные настройки).

Перед запуском создайте виртуальное окружение и установите зависимости:
  python -m venv venv
  venv\\Scripts\\activate
  python -m pip install -r requirements.txt

Если приложению нужны ключи/настройки из .env, используйте свой локальный .env из исходной папки.
