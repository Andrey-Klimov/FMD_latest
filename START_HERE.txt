FMD — последняя версия интерфейса
================================

Запуск на Windows:
1. Откройте PowerShell в этой папке.
2. Выполните:
   python -m pip install -r requirements.txt
   python app_landing.py
3. Откройте в браузере:
   http://127.0.0.1:5000/

Корневая страница автоматически перенаправляет на новый FMD.

Что изменено в этой версии:
1. Главная: поиск → фильтры → список компаний.
2. Поиск предлагает и компании/тикеры, и отрасли.
3. Фильтры: отрасль, диапазон выручки, диапазон EBITDA, валюта.
4. Слева от компании — галочки. При выборе 2+ появляется «Перейти к сравнению».
5. В сравнении остаются только выбранные компании; можно вернуться к полной выборке.
6. Кнопка «Столбцы» позволяет добавлять/убирать мультипликаторы, финпоказатели, рентабельность и рост.
7. Таблица сделана менее Excel-подобной: более высокие строки, только горизонтальные разделители, без сетки ячеек.
8. Единственная кнопка «Выгрузить». В меню: финпоказатели, котировки, отчетность/скриншоты, полный комплект.
9. В карточке компании рентабельность и рост встроены в «Финансовые показатели».
10. Клик по значению за 2024 или 2025 показывает справа источник/скриншот именно для выбранного года. Для сравнительной колонки 2024 явно объясняется, что она находится в отчете 2025 года.
11. В карточке есть вкладки «Финансовые показатели», «Источники», «Котировки».
12. Котировки отображаются графиком внутри вкладки карточки; правой таблицы цен нет.
13. Кнопки ZIP на экранах отсутствуют. ZIP может формироваться только как результат выбранного пользователем типа выгрузки.

Данные:
- baza_v2/01_base/agr_base.xlsx — основная база и история 2023–2025.
- baza_v2/02_kotirovki — сохраненные котировки.
- baza_v2/03_Отчетность_и_скриншоты — первичные отчеты и изображения источников.
- baza_v2/04_МСФО_Excel — Excel-выгрузки МСФО.
- static/data/fmd_latest_data.json — подготовленный слой данных для нового фронтенда.

Если изменились agr_base.xlsx или data/landing_data.json, пересоберите слой фронтенда:
   python build_latest_data.py
затем перезапустите app_landing.py.

Важно: предыдущие HTML/CSS/JS старого интерфейса удалены из templates/static. Основной новый фронтенд:
- templates/landing.html
- templates/company.html
- static/css/fmd_latest.css
- static/js/fmd_latest.js
- static/js/company_latest.js
