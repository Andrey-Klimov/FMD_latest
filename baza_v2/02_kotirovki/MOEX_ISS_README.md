# Котировки MOEX ISS

Для каждого тикера файл `<TICKER>_30d.csv` содержит последние 30 завершённых
торговых дней строго до текущей даты: дату, цену закрытия, количество акций,
объём и оборот торгов, число сделок и капитализацию.

`quotes_30d.json` — общий кэш ответов ISS. Он обновляется один раз в день при
первом обращении к сайту. Принудительное обновление выполняет endpoint
`POST /api/landing/quotes/refresh`.

Формулы (в миллионах валюты отчётности):

- Капитализация = `CLOSE × ISSUESIZE / 1 000 000`
- EV = `Капитализация + Чистый долг`
- EV/EBITDA = `EV / EBITDA`
- P/E = `Капитализация / Чистая прибыль`
- Net Debt/EBITDA = `Чистый долг / EBITDA`

Для отчётности в USD капитализация переводится из RUB по дневному закрытию
USD/RUB TOM (`USD000UTSTOM`) от MOEX ISS. При отрицательной или нулевой прибыли
либо EBITDA соответствующий коэффициент отображается как «н/д».
